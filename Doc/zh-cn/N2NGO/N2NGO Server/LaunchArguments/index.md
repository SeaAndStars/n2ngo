适用于 **N2N GO Server** 的启动参数

## 可用启动参数

**N2N GO Server** 的启动参数有以下选项：

* `CONFIG_PATH`

  *是否可选:* 可选

  *默认值:* `config.ini`

  *释义:* 手动指定 N2N GO Server 将要加载的配置文件路径；该项可以是绝对路径，亦可以是相对路径。
