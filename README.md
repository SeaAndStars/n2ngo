### 简介

N2N GO 是N2N的一个图形化界面，可以用于各种局域网联机游戏
本项目/仓库遵循 [GPL3.0](LICENSE) 协议

### 架构

| N2NGO Core | N2NGO             | N2NGO Server         | N2NGO Client Update  |
| ---------- | ----------------- | -------------------- | -------------------- |
| .NET 6     | .NET 6            | .NET 6               | .NET 6               |
| Library    | Application (WPF) | Application(Console) | Application(Console) |

### 构建

0. 安装  **.NET 6 SDK** ([https://dotnet.microsoft.com/zh-cn/download/dotnet/6.0](https://dotnet.microsoft.com/zh-cn/download/dotnet/6.0))
1. 将仓库克隆至本地
2. 构建解决方案:

 **Windows**: 使用  **Visual Studio 2022**  打开  **N2NGO/N2NGO.sln** ，使用菜单的  **生成 -> 生成解决方案**

 **Linux**: 使用 `cd N2NGO` 进入N2N GO 解决方案文件夹，使用 `dotnet build` 命令构建解决方案
