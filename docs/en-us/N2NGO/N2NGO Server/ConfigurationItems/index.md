Configurations for **N2N GO Server**

Configuration will be loaded at `ServerConfig` in **Server In Console**.

## Items

Configuration Items for **N2N GO Server**:

* #### `IPv4`

  *Default:* `0.0.0.0`

  *Description:* Listening Address in **IPv4**


* #### `PortV4`

  *Default:* `7476`

  *Description:* Listening Port for **IPv4**


* #### `IPv6`

  *Default:* `::`

  *Description:* Listening Address in **IPv6**


* #### `PortV6`

  *Default:* `7476`

  *Description:* Listening Port for **IPv6**

  > **Note:** <br>
  > Some platform features is required if both IPv4 and IPv6 listens the same port.
  >


* #### `EnableIPv6`

  *Default:* `1`

  *Description:* <br>
  Start **IPv6** server<br><br>
  `0` - Disabled<br>
  Any Value - Enabled
