Launch Arguments for **N2N GO Server**

## Arguments

Arguments available for **N2N GO Server**:

* `CONFIG_PATH`

  *Optional:* Optional

  *Default:* `config.ini`

  *Description:* Specifies the path to the configuration file that N2N GO Server will load; path can be absolute or relative.
